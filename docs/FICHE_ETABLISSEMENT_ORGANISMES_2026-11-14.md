# Organisation de la fiche établissement

Présentation harmonisée de la zone Choisir les caisses et organismes, dans le formulaire et dans la fiche de consultation :

1. Organismes de recouvrement des cotisations : organisme, caisse locale / nom exact, numéro de compte / affiliation.
2. Retraite de base : régime, caisse gestionnaire / rattachement, référence facultative. Informations de rattachement, sans création d’une seconde cotisation vieillesse.
3. Retraite complémentaire : groupe, institution, numéro d’adhésion / affiliation. Les anciens champs retirementBody, retirementOffice et retirementReference restent inchangés.
4. Prévoyance : organisme, nom exact, référence de contrat.
5. Mutuelle / complémentaire santé : organisme, nom exact, référence du contrat santé.
6. Caisse des congés payés : caisse, nom exact, numéro d’adhérent.
7. Accidents du travail / maladies professionnelles (AT/MP) : code risque, taux, date d’effet, fin de validité facultative, référence de notification.

Deux colonnes de blocs sur écran large, une colonne sur petit écran. Les champs d’un même organisme restent regroupés verticalement. Le bloc AT/MP occupe une ligne complète. La recherche SIRET, les validations, les paramètres enregistrés et le paiement au 5 sont conservés.

Sauvegarde en brouillon, sans publication du site.
