# Choix des caisses — version d’essai

Chaque bloc possède une liste déroulante : recouvrement, retraite de base, retraite complémentaire, prévoyance, mutuelle, congés et AT/MP.

Ajouts : Urssaf régionales, CGSS, CSS Mayotte, Carsat, CNAV Île-de-France, caisses CIBTP régionales et antennes Antilles-Guyane, caisse AT/MP. Les listes ne sont pas exhaustives. Le choix Autre permet une saisie dans le champ exact associé ; une ancienne valeur personnalisée reste proposée et sélectionnée. Aucun taux ni affiliation n’est déduit du choix. Les données et bulletins historiques sont conservés.
