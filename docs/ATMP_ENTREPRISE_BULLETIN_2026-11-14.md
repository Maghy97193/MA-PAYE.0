# AT MP dans la fiche entreprise et le bulletin

Ajout en brouillon des champs code risque, taux notifié, date d’effet, fin de validité facultative et référence de notification. Ces paramètres ne sont pas déduits du SIRET ni du code APE. Aucun code réel ni taux de 6,48 % n’est prérempli sans document applicable.

Le code et le taux enregistrés apparaissent sur les nouveaux bulletins, à l’écran, à l’impression et dans le PDF. Les anciens bulletins conservent leur photographie employeur ; une mise à jour d’entreprise ne réécrit pas l’historique.

Dans la préparation, une commande explicite ajoute ou actualise la ligne AT/MP à partir de la fiche entreprise. Elle reprend l’assiette gross du moteur de test, un taux salarié de zéro et le taux employeur renseigné. Elle demande une vérification des cotisations, prévient les doublons et bloque la reprise du taux si ses dates ne couvrent pas tout le mois. Les taux distincts selon les catégories de salariés et les assiettes réglementaires restent à contrôler.

Conservation dans les sauvegardes entreprise et bulletin existantes. Paramètres disponibles pour la future correspondance DSN, sans émission DSN. Site en ligne inchangé.

Référence officielle consultée le 14 novembre 2026 : https://www.ameli.fr/entreprise/votre-entreprise/cotisation-atmp/calcul-taux-atmp-entreprises-btp
