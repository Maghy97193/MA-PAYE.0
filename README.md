Branche dédiée : `ma-paye-0-version-btp`.

## État

Version de développement et de test. Le suivi des heures, les sous-totaux hebdomadaires, les totaux mensuels, l’import Excel/CSV et le transfert contrôlé sont implémentés. L’écran de connexion par e-mail est préparé mais l’authentification e-mail n’est pas activée. La DSN reste une préparation sans génération ni transmission.

La liaison avec BATI.0 reste en attente de vérification par Maguy. Aucune connexion mobile individuelle ni mise à jour réglementaire autonome des taux n’est activée. Les données de démonstration restent dans le navigateur.

Aucune mise en ligne, fusion ou modification de BATI.0 n’est déclenchée par la création de cette branche.
